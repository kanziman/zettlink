# 노션 개발자는 코드를 이렇게 읽습니다

> https://www.youtube.com/watch?v=iv60GIHpijE

## 요약

노션 디자인 엔지니어 제프리 릿(Geoffrey Litt)이 AI 에이전트 시대에 코드를 읽는 새로운 방법을 소개한 발표를 정리한 영상이다. AI가 한 번에 수만 줄의 코드를 바꾸는 시대에 줄 단위 코드 리뷰는 한계에 달했으며, '인지 부채(Cognitive Debt)'—코드는 멀쩡하지만 내가 그 코드를 모르는 상태—가 새로운 문제로 떠오르고 있다. 발표자는 교육학에서 차용한 세 가지 접근법(설명서·퀴즈·놀이터)을 활용한 프롬프트를 공개하며, 검증은 AI에게 맡기되 이해는 개발자 본인이 챙겨야 한다고 강조한다. AI로 설명서를 생성하는 과정에서 몇 달간 발견하지 못했던 버그를 찾아낸 실제 사례도 소개한다.

## 인사이트

- AI 에이전트가 코드 5만 줄을 한 번에 변경하는 시대에는 줄 단위 코드 리뷰가 더 이상 현실적이지 않다.
- '인지 부채(Cognitive Debt)'는 코드 자체가 아닌 개발자의 머릿속에 쌓이는 새로운 형태의 부채다.
- 코드 검증은 점점 AI에게 맡기되, 코드 구조에 대한 이해는 개발자 본인이 반드시 챙겨야 한다.
- 교육학의 세 가지 학습 원리(설명서·퀴즈·놀이터)를 코드 이해에 적용하면 효과적이다.
- 구조를 아는 개발자는 머릿속에서 시뮬레이션이 가능해 아이디어가 자연스럽게 나오지만, 모르면 매번 AI에 물어봐야 해 창의적 사고가 차단된다.
- AI에게 코드 변경 설명서를 작성시키면 부수적으로 잠재 버그까지 발견하는 효과가 있다.
- 프롬프트 스킬(explain-diff)을 Claude Code 등에 설치해 '구조부터 이해시키고 코드는 마지막에 보여줘' 방식으로 즉시 활용할 수 있다.
